## 📦 版本选择

从当前版本开始，原来的四个变体正式精简为 **完整版 / 轻量版**。

| 版本 | 说明 |
|---|---|
| **完整版 Full** | 完整功能：翻译设置、桌宠、频谱、媒体预览、ffmpeg、MIDI 艺术等 |
| **轻量版 Lite** | 主要保留中文翻译、中文字体及基础功能，体积更小 |

> 💡 大多数用户推荐选择 **完整版**。  
> 如果只需要中文界面、不需要桌宠和扩展工具，可以选择 **轻量版**。

## ✨ 主要更新

### 🌐 翻译系统

- 支持导入自定义 **JSON 翻译表**
- 支持多张翻译表切换与热重载
- 新增翻译兜底开关
- 内置 **997 条翻译词条 + 动态翻译规则**
- 支持导出内置翻译模板
- 未覆盖的词条可选择使用内置中文翻译或保持英文原文
- 可以用于制作中文、日文或其他语言翻译表

### 🔤 自定义字体

支持导入：

`TTF` / `TTC` / `OTF`

并提供三种作用范围：

| 模式 | 说明 |
|---|---|
| 扩容 | 英文数字保持原版字体，仅中文使用自定义字体 |
| 界面 | 整个 FLM 主界面使用自定义字体 |
| 全部 | FLM 主界面与扩展工具界面全部使用自定义字体 |

- 内置细体与粗体仍然保留
- 翻译设置面板可预览当前字体效果
- 字体修改后需要重新启动 FLM 生效

### 🎛️ 音频可视化

- 新增实时音乐频谱
- 支持低频脉冲效果
- 可调整柱数、柱高、圆角、不透明度等参数
- 支持色轮选色与手动输入颜色
- 内置大量中英文颜色名称
- 音频试听时，频谱也会同步响应

> 音频可视化默认关闭，可在面板中自行开启。

### ▶️ 音频试听

- 音频导入页面新增直接试听按钮
- 点击即可播放，再次点击停止
- 播放完成后自动复位
- 试听按钮与文件选择操作相互独立
- 系统无法直接播放的格式可调用 ffmpeg 自动转码后试听

支持包括：

`APE` / `WV` / `WMA` / `MP2` / `AIF` / `AIFF` / `DSF` / `DFF` / `TAK` / `TTA` / `MPC`

等格式。

### 🎬 视频全屏播放

- 视频选择页面支持全屏预览
- 支持播放 / 暂停
- 支持拖动进度条
- 显示当前时间与总时长
- 播放结束后自动循环
- 保持视频原始比例，不拉伸画面
- 控制栏会在无操作时自动隐藏
- 页面支持淡入淡出动画

### 🔍 导入页搜索

- 音频与视频导入页面新增搜索功能
- 搜索不区分大小写
- 音频支持递归搜索当前目录及子目录
- 视频支持搜索已扫描的视频列表
- 搜索结果显示文件所在目录
- 清空搜索框即可恢复普通浏览

### 🐱 桌宠

完整版包含可交互桌宠：

- 支持自由拖动
- 双击切换动画
- 支持调整桌宠大小
- 支持调整动画速度
- 长时间拖动可触发「挣脱」彩蛋
- 拖动过程中显示专属表情
- 连续点击可暂时隐藏桌宠

### 🎹 MIDI 艺术

支持：

- 文字转 MIDI
- 图片转 MIDI
- 音高映射
- 力度包络

### 🧪 ffmpeg 音频工具

支持：

- 视频分离音频
- 常见音频格式互相转换

包括：

`MP3` / `FLAC` / `WAV` / `OGG` / `OPUS` / `M4A`

### 👥 在线人数

完整版右下角支持实时显示：

**在线 N 人**

- 每 60 秒自动刷新
- 可在设置中关闭界面显示
- 界面显示与后台在线统计相互独立
- 轻量版不显示在线人数，但仍保留在线心跳统计

> 关闭在线人数显示仅隐藏界面提示，不会停止在线统计请求。

- 更新提示由服务器版本号控制
- 优化部分网络环境下的版本检查稳定性

### 🎨 主题与界面

- 保留马卡龙主题
- 支持液态玻璃相关界面效果
- 优化部分面板布局与状态同步
- 修复部分主题下的控件显示异常

### 🛡️ 完整性保护

- 部分代码混淆

## 🔬 汉化原理

项目采用 **Frida 运行时动态汉化**：

1. 将 Frida Gadget 注入 APK
2. 应用启动时加载汉化脚本
3. 定位 FL Studio Mobile 的文本绘制函数
4. 在文字显示到界面前进行动态替换

简单来说：

> 给 FL Studio Mobile 增加了一层运行时的「翻译层」。

这种方式方便后续维护翻译内容、增加动态规则，并减少对原始界面文件的大规模修改。
